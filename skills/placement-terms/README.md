# 定增条款解读（`placement-terms`）

向特定对象发行类公告。命门是「定价规则」不等于「已确定价格」,数量上限往往有两个计算口径,以及尚需履行的程序必须完整列出。

## 何时匹配

- 原文关键词：向特定对象发行、定向增发、定价基准日、募集资金、认购
- 提问关键词：定增、发行价格、募集资金、发行对象、发行数量

## 必答子问题

- 本次发行的定价规则是什么?最终发行价格在哪个环节确定?
- 发行数量的上限是如何约定的?涉及哪些计算口径?
- 募集资金总额的上限与用途是如何安排的?
- 发行对象的范围与最终确定方式是什么?
- 目前已经完成哪些程序?尚需哪些审议或核准才能实施?

## 风险检查单

- 定价规则是否被误读为已经确定的价格
- 数量上限涉及的不同口径是否分别列示
- 尚需履行的程序是否完整列出
- 「不超过」与「确定为」的表述差异是否被保留

每项须在备忘录中有着落;没有着落的会记入审计并写进 `memo.checklist`,而不是悄悄消失。

## 归因与反证

- 归因：公司对发行前景与募投效益的表述必须归因
- 反证槽：公告中是否存在可能导致本次发行无法实施的条件

## 技能级禁语

叠加在全局合规规则之上，只增不减：`打新`、`套利`、`目标价`、`买入时点`
