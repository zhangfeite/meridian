# 减值计提解读（`impairment-readout`）

计提减值准备类公告。逐项与合计、对净利润与所有者权益的影响、最大单项占比(由管线计算),以及数据是否经审计。

## 何时匹配

- 原文关键词：计提减值、减值准备、资产减值损失、信用减值损失、存货跌价准备
- 提问关键词：减值、计提、跌价

## 必答子问题

- 本期计提了哪些类别的减值准备?各类金额分别是多少?
- 各项减值准备合计多少?表格标注的金额单位是什么?
- 哪一项金额最大?它占合计的比例是多少?
- 本次计提对当期净利润与所有者权益的影响分别是多少?
- 相关财务数据是否经过审计?公告如何表述其确定性?

## 必算派生数

- 最大单项占合计比例 = 该项金额 / 各项合计金额

## 风险检查单

- 计提数据是否未经审计,以及公告对此的表述
- 是否存在转回或为负数的项目,其符号是否保留
- 表格单位是否为万元等非元口径,换算是否被误写
- 公告是否说明计提依据与减值测试方法

每项须在备忘录中有着落;没有着落的会记入审计并写进 `memo.checklist`,而不是悄悄消失。

## 归因与反证

- 归因：「充分」「谨慎」「公允」等评价性表述必须归因到公告或管理层
- 反证槽：管理层对计提充分性的表述是否存在反方迹象

## 技能级禁语

叠加在全局合规规则之上，只增不减：`买入时点`、`卖出信号`、`抄底`、`目标价`
