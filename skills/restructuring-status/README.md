# 重整程序状态（`restructuring-status`）

破产重整与预重整类公告。本技能的命门是程序位置:「债权人提出申请」与「法院裁定受理」是两件事,公告自身的不确定性表述必须原样保留。

## 何时匹配

- 原文关键词：重整、预重整、破产、管理人、债权人申请
- 提问关键词：重整、破产、债权人、管理人

## 必答子问题

- 提出申请的是谁?与公司是什么关系?
- 申请所主张的债权金额与对应法律文书分别是什么?
- 该事项目前处于司法程序的哪个阶段?
- 公告对后续程序与时间安排是如何表述的?
- 公告提示了哪些对股票交易与上市地位的影响?

## 风险检查单

- 「提出申请」与「裁定受理」是否被严格区分
- 是否存在风险警示叠加或终止上市的表述
- 公告自身的不确定性表述是否被保留而非削弱
- 涉及多份文件时,各文件所述时点的先后关系是否明确

每项须在备忘录中有着落;没有着落的会记入审计并写进 `memo.checklist`,而不是悄悄消失。

## 归因与反证

- 归因：董事会意见与公司对前景的预期必须归因
- 反证槽：公告中是否存在削弱重整前景的表述

## 技能级禁语

叠加在全局合规规则之上，只增不减：`抄底`、`博弈`、`套利`、`目标价`、`买入时点`
