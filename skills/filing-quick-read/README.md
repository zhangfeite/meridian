# 公告快解(兜底)（`filing-quick-read`）

任何未被专门技能认领的公告。给出核心事项、涉及主体、关键数字口径、所处阶段与公告自身的风险提示。

## 何时匹配

- 原文关键词：公告、董事会、特此公告
- 提问关键词：公告、披露、什么事、怎么回事
- 兜底技能：其他技能都不命中时使用

## 必答子问题

- 本公告披露的核心事项是什么?发生于何时?
- 涉及哪些主体?各自的角色是什么?
- 公告给出了哪些关键数字?各自的口径与单位是什么?
- 该事项目前处于哪个阶段?后续还需要哪些程序?
- 公告本身提示了哪些风险或不确定性?

## 风险检查单

- 数据是否经过审计,公告如何表述其确定性
- 是否存在尚未完成的程序或尚待确定的事项
- 公司自述与可独立核查的事实是否已经区分
- 是否存在期间口径或单位口径的差异

每项须在备忘录中有着落;没有着落的会记入审计并写进 `memo.checklist`,而不是悄悄消失。

## 归因与反证

- 归因：公司、董事会或股东的自述性表述必须归因到发言主体
- 反证槽：公告中是否存在与主要结论方向相反的表述

## 技能级禁语

叠加在全局合规规则之上，只增不减：`买卖时点`、`目标价位`、`建仓`、`抄底`
