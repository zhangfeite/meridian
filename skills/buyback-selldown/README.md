# 回购与库存股处置（`buyback-selldown`）

回购股份及其后续处置类公告。命门是处置主体判别——公司卖自己账户里的库存股不是股东减持;回购均价与处置溢价由管线计算,不抄。

## 何时匹配

- 原文关键词：回购、库存股、回购专用证券账户、集中竞价、减持回购股份
- 提问关键词：回购、库存股、减持、处置

## 必答子问题

- 本次处置的股份来源是什么?处置主体是公司自身还是股东?依据是哪一句原文?
- 本次处置的数量、占总股本比例、成交金额与均价分别是多少?发生在哪一天?
- 此前回购这批股份的总数量、总金额与成交价区间分别是多少?
- 按已披露数字计算,回购均价与本次处置均价分别是多少?两者是什么关系?
- 处置后剩余可处置的股份还有多少?处置窗口是如何约定的?

## 必算派生数

- 回购均价 = 回购总金额 / 回购总数量
- 处置均价相对回购均价的倍数 = 处置均价 / 回购均价

## 风险检查单

- 处置主体是公司还是股东,是否被误写为股东减持
- 占所持股份与占总股本两个比例口径是否分别列示
- 处置窗口、数量上限与前置公告要求是否说明
- 计算所得的数字是否标明为衍生数并给出公式

每项须在备忘录中有着落;没有着落的会记入审计并写进 `memo.checklist`,而不是悄悄消失。

## 归因与反证

- 归因：公司对处置目的与资金用途的表述必须归因
- 反证槽：公告中是否存在限制处置节奏或数量的条款

## 技能级禁语

叠加在全局合规规则之上，只增不减：`套利`、`目标价`、`买入时点`、`跟风`
